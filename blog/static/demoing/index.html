og:video demo

It's not 3D. It's this video.

Paste this page's URL into iMessage. The link card plays the clip below inline, muted, on loop. That is the entire Polycam trick.

To film it:

  1. Tap Share this page above
  2. Pick Messages in the share sheet
  3. Send it to yourself (or a friend)
  4. The bubble plays the video inline. That's og:video, not 3D.

iMessage fetches this page's HTML itself, reads the og:video tag, and renders the MP4 in the card. The share button (or a paste, same thing) only hands over the URL. No USDZ, no interactive 3D, no JavaScript API.

The exact tags this page uses:

<meta property="og:title" content="Paste this link into iMessage. The card plays video.">
<meta property="og:image" content=".../demoing/poster.jpg">
<meta property="og:video" content=".../demoing/demo.mp4">
<meta property="og:video:type" content="video/mp4">
<meta property="og:video:width" content="794">
<meta property="og:video:height" content="1080">
